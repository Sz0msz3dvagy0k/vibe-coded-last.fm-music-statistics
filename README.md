# Navidrome Dashboard

A modern music listening activity dashboard using Last.fm and Spotify APIs.

## Features
- Real-time listening statistics from Last.fm
- Artist and album images from Spotify
- Colorful graphs and visualizations
- Navidrome-inspired UI with modern animations
- User-friendly and responsive design

## Tech Stack
- **Frontend**: React with Vite
- **Backend**: Node.js with Express
- **APIs**: Last.fm, Spotify
- **Charts**: Recharts
- **Styling**: CSS with animations

## Project Structure
```
navidrome-dash/
├── backend/        # Node.js Express server
├── frontend/       # React application
├── docs/          # Context and planning documents
└── README.md
```

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## APIs
- Last.fm API for listening history
- Spotify API for artist/album images
